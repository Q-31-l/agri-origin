# 微信小程序上传指南

> 面向本项目的实际操作手册。代码侧已经准备完毕（`npm run build:mp-weixin` 可产出完整包），
> 剩下的是**账号资料**与**服务器域名**两类外部配置。

---

## 一、必须先知道的一件事：域名备案是硬门槛

微信小程序对 `wx.request` 有白名单限制：**请求域名必须已完成 ICP 备案**，且不能是 IP、
不能是动态域名。当前项目用的是

```
https://8-147-61-0.sslip.io
```

`sslip.io` 是境外免费动态 DNS，**没有 ICP 备案，无法通过微信后台的域名校验**。

由此产生三种可用性，差别很大：

| 场景 | 能否连后端 | 说明 |
|---|---|---|
| 微信开发者工具（模拟器） | ✅ 可以 | 勾选「不校验合法域名」即可 |
| 真机预览 / 真机调试 | ✅ 可以 | 同样受「不校验合法域名」开关控制，预览码有效 |
| 体验版 / 正式版 | ❌ 不行 | 强制校验，必须换备案域名 |

**结论**：答辩演示、真机试用都能跑（用**预览码**，不是体验版）；
要真正发布上线，必须先解决域名备案。三条路：

1. **买域名 + 备案**（阿里云/腾讯云，个人备案约 7–20 天）→ 把 nginx 与新域名对上，重签证书；
2. **用微信云开发转发**：小程序请求云函数，云函数再去请求你的服务器，绕开域名白名单（改造量中等）；
3. **只做演示**：发给老师/评委的是**预览二维码**，不是正式小程序码。

> 本指南按"先把演示跑起来"来写，正式发布那一步单独标注。

## 二、需要准备的东西（清单）

### 1. 已有：小程序账号

从微信公众平台 <https://mp.weixin.qq.com> 登录后，在
**开发 → 开发管理 → 开发设置** 里拿到 **AppID（小程序 ID）**，形如 `wx1a2b3c4d5e6f7g8h`。

> AppSecret 不用填进前端，只在后端配置微信登录时才需要。

### 2. 小程序名称（本项目踩过坑，见下方说明）

规则：4–30 个字符（一个中文算 2 个），全平台唯一，不能含"微信/腾讯"等词。

#### ⚠️ "农安链溯源"为什么会被拦

在后台填这个名字会提示：

> 你申请的名称可能涉及特定行业领域，建议提供以下材料 3 选 1：
> 1. 广电总局版号批文及对应运营授权；2. 商标注册证及授权使用书；
> 3. 已上线产品在应用平台的后台截图……否则可能不会通过审核。

**这是系统的关键词初检**，踩了三个点：

| 片段 | 触发的规则 | 后果 |
|---|---|---|
| **链** | 被识别为区块链业务 | 区块链信息服务需**网信办备案**（个人主体基本办不下来） |
| **溯源** | 被识别为检测认证/信息服务 | 需相关行业资质 |
| **农安** | 吉林省长春市**农安县**，是县级行政区划 | 非该地区主体使用地名，可能被要求授权书 |

官方社区运营专员的说法是：**"提示仅为平台系统初步名称检测结果，不代表最终的命名，可以先行提交审核"**——
所以不是硬性拒绝，但个人主体在这类关键词上通过率很低。

#### 推荐的替代名称

小程序名称和应用内显示的品牌**可以不一样**：小程序叫"农安农事本"，打开后登录页仍然可以显示
"农安链溯源 AGRI-ORIGIN"，完全合规。所以改名称不破坏品牌一致性。

| 候选名 | 风险 | 说明 |
|---|---|---|
| **禾安农事本** | 低 | "禾安"谐音品牌，避开地名与行业词；"农事本"是工具定位，最稳 |
| **农安农事本** | 中 | 保留品牌原名，但"农安"仍是县名，可能被单独要求授权 |
| **田记农事本** | 低 | 纯工具命名，与品牌弱关联 |
| **农事记录本** | 最低 | 最朴素，几乎不会被拦，但辨识度低 |

> 建议先试 **农安农事本**；若因地名被驳回，再换 **禾安农事本**（图标、代码都不用改，
> 名称审核未通过不占用每年 2 次的改名次数）。

#### 简介怎么写（同样要审核）

名称避开了"链"，简介里可以把技术说清楚，反而更容易让评审理解这是教学/工具类应用：

> 面向种植户的农产品生产记录工具：记录农事操作、采收、检测与销售信息，生成一物一码，
> 消费者扫码可查看产地与检测报告。

避免在简介里堆"区块链""数字资产""挖矿"这类词。

### 3. 小程序图标

已生成好，直接用（图形与系统内的品牌徽章同源：草坡 + 破土双叶 + 一枚链上节点）：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `docs/assets/mp-icon-144.png` | 144×144 | 微信后台上传（最小要求），16 KB |
| `docs/assets/mp-icon-512.png` | 512×512 | 素材位/分享卡片，152 KB |
| `docs/assets/mp-icon-1024.png` | 1024×1024 | 高清原图，484 KB |
| `docs/assets/mp-icon-circle-preview.png` | — | **仅预览**：微信裁圆后的实际效果 |

**为什么是方形满出血**：微信会把头像裁成圆形。如果直接交带圆角的设计图，
裁完之后四个角会露出透明底或白边。这张图背景铺满整张方图、主体压在中心圆内，
裁圆后边缘是连续的渐变，不会出现白角。

### 4. 服务类目（选错是驳回头号原因）

**结论：选「工具 → 信息查询」，无资质要求，个人主体可选。**

参考微信官方类目说明：`工具 / 信息查询` 适用于"提供信息查询功能等服务"，**资质要求：无**。
而且有同类先例——个人开发者做的农业识别小程序「识农害」就是 `工具 / 信息查询` 上线的，
说明农业场景走工具类目是被接受的。

| 层级 | 选择 | 适用判断 |
|---|---|---|
| 一级 | **工具** | — |
| 二级 | **信息查询** | 主选：消费者扫码查看产地、检测、流转信息 |
| 二级 | **效率**（备选） | 若评审认为核心是"记录"，改选这个，同样无资质要求 |

两个都在个人主体开放清单内，且都无资质门槛。**建议只选一个**，类目越少审核越清晰。

#### 千万不要选这些

| 类目 | 为什么不能选 |
|---|---|
| 商业服务 → **农林牧渔** | 官方描述含"交易等服务"，容易被要求农业相关资质；且个人主体开放清单里未稳定列出 |
| 电商平台 / 食品经营 | 需要《食品经营许可证》，且会被要求接入微信支付 |
| 教育 → 教育信息服务 | 需要说明教育用途，与"农事记录工具"对不上，反而增加解释成本 |
| 医疗 / 金融 / 新闻 | 与本项目无关，属于高危类目 |

#### 类目、名称、简介必须三者一致

审核会交叉核对。如果名称叫「农安农事本」、类目是「工具-信息查询」，
简介却写"农产品交易平台"，直接驳回。

三者对齐的口径：

```
名称  农安农事本                 ← 工具定位
类目  工具 / 信息查询             ← 查询/记录
简介  面向种植户的农产品生产记录工具，
      记录农事、采收、检测与销售信息，一物一码，消费者扫码可查。
```

> 类目提交后修改需要重新审核，个人主体还有次数限制，**第一次就选准**。

### 5. 用户隐私保护指引

2023 年起强制。在 **设置 → 服务内容声明 → 用户隐私保护指引** 里填写并提交，
需要勾选本项目实际用到的两项：

- **位置信息**：用于记录农事作业与采收地点（对应代码里的 `getLocation` / `chooseLocation`）
- **相册/摄像头**：用于上传现场实证照片、扫码溯源

> 这一项不填，真机上调用 `wx.getLocation` 会直接失败，且审核会被驳回。

### 6. 接口权限：`wx.getLocation`

2022 年起 `wx.getLocation` 变成了**需要申请的接口**。在
**开发 → 开发管理 → 接口设置** 里申请「获取当前的地理位置、速度」，
填写使用场景（农产品溯源记录作业地点）。

> 申请一般 1–3 个工作日。**没通过之前**，真机上定位会失败——
> 但代码里已经做了降级（定位失败自动改用农场档案地址），不影响主流程。

### 7. 服务器域名（仅正式版需要）

**开发 → 开发管理 → 开发设置 → 服务器域名**，四个框都填同一个域名：

| 类型 | 填什么 |
|---|---|
| request 合法域名 | `https://你的备案域名` |
| uploadFile 合法域名 | 同上 |
| downloadFile 合法域名 | 同上 |
| socket 合法域名 | `wss://你的备案域名`（WebSocket 实时刷新用） |

当前 `8-147-61-0.sslip.io` **填不进去**（会提示域名未备案），所以走预览码演示。

## 三、代码侧要改的只有一处：AppID

打开 `frontend/uni-app/src/manifest.json`，把 `mp-weixin.appid` 填上：

```json
"mp-weixin": {
  "appid": "wx1a2b3c4d5e6f7g8h",   // ← 换成你的 AppID
  "setting": {
    "urlCheck": false,             // 开发期不校验域名，保持 false
    ...
  }
}
```

其余配置都已完成：

- **接口地址**：`.env.production` 里的 `VITE_API_BASE=https://8-147-61-0.sslip.io`，
  打包时自动注入（`src/config/env.js` 读取）。H5 生产构建会忽略它、强制走同域 `/api`，
  两边互不影响。
- **定位权限**：`permission.scope.userLocation.desc` 与 `requiredPrivateInfos` 已声明。
- **包体积**：主包 941 KB，图标以 base64 内嵌（55 KB / 34 个），远低于 2 MB 限制。

改完重新构建：

```bash
cd frontend/uni-app
npm run build:mp-weixin
# 产物：dist/build/mp-weixin
```

## 四、导入开发者工具

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开 → **导入项目**
   - 目录：`frontend/uni-app/dist/build/mp-weixin`
   - AppID：填你自己的
   - 后端服务：不使用云服务
3. 进入后，点右上角 **详情 → 本地设置**，勾选：
   - ☑ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
   - ☑ 将 JS 编译成 ES5（兼容老机型，可选）
4. 模拟器里就能登录、看数据了（用下面的演示账号）

**演示账号**（密码统一 `123456`）：

| 账号 | 角色 | 适合演示什么 |
|---|---|---|
| `farmer01` | 农户 | 农事记录、采收登记、上传现场照片 |
| `inspector01` | 检测机构 | 质检报告上传 |
| `regulator01` | 监管 | 异常处置、链上存证追溯 |
| `admin` | 管理员 | 全功能 |

> 不同账号登录看到的菜单不同，这是权限控制在生效，不是 bug。

## 五、真机预览（答辩演示用这个）

开发者工具顶部 **预览** → 生成二维码 → 手机微信扫码。

- 手机与电脑不必同一网络，预览码走微信通道
- **前提**：第四步那个「不校验合法域名」必须勾着，否则真机上接口会全失败
- 预览版有效期较短，演示前一天重新生成一次

## 六、上传体验版 / 提交审核（需要备案域名）

如果域名问题已解决：

1. 开发者工具 **上传** → 填版本号（如 `1.0.0`）与备注
2. 微信公众平台 **管理 → 版本管理** → 刚上传的版本 → **提交审核**
3. 审核前确认：类目已选、隐私指引已提交、`getLocation` 接口已通过
4. 审核通过后 **发布**，生成正式小程序码

当前域名未备案，这一步会卡在审核（"服务端接口不可访问"）。**演示阶段不必走这里。**

## 七、常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `request:fail url not in domain list` | 域名未加白名单 / 未勾选不校验 | 开发期勾「不校验合法域名」；正式版换备案域名 |
| 登录后所有列表空白、控制台 401 | 接口地址错（历史 bug：曾写死不存在的 `api.agri-origin.com`） | 确认 `.env.production` 的 `VITE_API_BASE` 是真实域名，重新构建 |
| `getLocation:fail auth deny` | 用户拒绝授权 | 代码已降级为农场档案地址；可在「我的-设置」引导重新授权 |
| `getLocation:fail the api need to be declared in the requiredPrivateInfos` | 后台未申请接口权限 | 开发管理 → 接口设置 → 申请 `wx.getLocation` |
| 头像显示成方块/白角 | 上传了带圆角的图 | 用 `mp-icon-1024.png`（方形满出血） |
| 审核驳回「服务内容与实际不符」 | 类目选错 | 改成「工具-效率」或「教育-教育信息服务」 |
| 填名称时提示「可能涉及特定行业领域」 | 名称含「链」「溯源」等行业词，或含县级以上地名 | 换名（见第二章候选），名称审核未过不占改名次数 |
| 扫码进入空白页 | 溯源页域名未在 downloadFile/file 白名单 | 同 request 域名处理 |

## 八、后端可选配置：微信一键登录

小程序登录页有「账号登录 / 微信登录」两个页签。**账号登录开箱即用**；
要让「微信一键登录」拿到真实 openid，需要在服务器上配两个环境变量：

```bash
# /opt/agri-origin/app/backend.env
WX_APPID=wx1a2b3c4d5e6f7g8h
WX_SECRET=你的AppSecret
```

配完 `systemctl restart agri-backend`。

不配也能用：后端会自动进入 **mock 模式**（固定 openid `mock-openid-local-demo`），
日志里会明确写"处于 mock 模式…仅用于本地联调"，不会伪装成真实微信登录。
mock 模式下首次仍需绑定一个已有账号，因此**演示时直接用账号密码登录更省事**。
