## 关于"未上链"标识

截图中所有存证状态均为「未上链」，因为截图环境未接入 FISCO-BCOS 节点
（`application.yml` 中 `chain.enabled=false`）。

这是刻意保留的真实状态：演示模式下系统会如实把存证标记为 `SKIPPED`，
并在一致性校验时提示「未存证」，**不会显示虚假的交易哈希与"存证成功"**。

答辩时若已搭好链，重新走一遍业务即可得到带真实 `txHash` 与区块高度的截图，
此时 `pc-07-chain.png` 会显示实际的存证流水而非空状态。

## 重新采集

```bash
# 1. 启动三个服务（数据库、后端、前端）
# 2. 用无头浏览器脚本采集（需 puppeteer-core + 本机 Edge/Chrome）
node shoot.js
```

采集脚本建议放在仓库外，避免把开发依赖带进版本库。
